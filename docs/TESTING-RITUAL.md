# 归航时刻 / 悬浮头像 测试说明

## 方法一：Popup 预览（推荐，立即可测）

1. **打开任意普通网页**  
   例如 `https://www.baidu.com` 或任意站点。  
   ⚠️ 不要用 `chrome://`、扩展商店页、`about:` 等，content script 不会注入，收不到消息。

2. **打开扩展 Popup**  
   点击浏览器工具栏里的 Y2K-ifier 图标。

3. **点击「预览归航时刻」**  
   在「每日归航时刻」区域找到该按钮并点击。

4. **预期效果**  
   - 当前页面**右下角**出现悬浮框：复古头像 +「归航」/ "Ritual" 文案。  
   - **点击该悬浮框**后，弹出今日信息卡片（冲浪日志、时间轴、下班提示等）。  
   - 再次点击卡片外的遮罩或卡片上的 × 可关闭。

---

## 方法二：到点自动触发

1. 在 Popup 中**开启「开启归航提醒」**。  
2. 将**提醒时间**设为「当前时间 + 1～2 分钟」，例如当前 14:03 就设为 `14:05`，然后保存。  
3. **保持当前标签页**在任意普通网页（不要关掉或切到 chrome://）。  
4. 等待 1～2 分钟。

**预期效果**  
- 到点后当前页面右下角出现同样的悬浮头像。  
- 同时会新开一个「新标签页」（带 `?ritual=1` 的 newtab）。  
- 点击悬浮头像即可打开今日信息卡片。

---

## 若悬浮框 / 卡片没出现

- **确认页面类型**：必须是普通 HTTP/HTTPS 网页，content script 才会注入。  
- **重新加载页面**：修改 content 后需刷新该页面，或重新打开该页。  
- **查看控制台**：F12 → Console，看是否有报错（如 `Receiving end does not exist` 多为 tab 未注入）。  
- **确认扩展已加载**：`chrome://extensions` 中 Y2K-ifier 已启用，必要时点击「重新加载」扩展。
