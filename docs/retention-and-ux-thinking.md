# Y2K-ifier 留存与「好用」思路梳理

## 一、当前体验里「还不够好用」在哪

### 1. 价值要用户自己「碰巧发现」

- **装完后的路径**：点扩展图标 → 弹窗里只有两个开关（复古 / CRT）→ 关掉弹窗 → 去随便开个网页 → 才看到效果。
- **问题**：核心价值（整站变复古）没有在安装后 10 秒内被展示；用户要自己建立「开开关 = 网页会变」的因果，很多人没走到这一步就卸了。
- **结论**：不是功能少，而是**价值呈现太晚、太被动**。

### 2. 没有「用完了得到什么」

- 现在：打开开关 → 看网页 → 关掉。没有任何**可带走的东西**（截图、链接、卡片、分享图）。
- 用户心理：好玩一下就够了，没有「这是我用 Y2K 做的」的归属感，也没有分享动机。
- **结论**：缺少**产出型动作**（生成、保存、分享），所以很难「好用」到让人想留。

### 3. 唯一有氛围的页面被藏起来了

- **选项页**：XP 壁纸 + 复古搜索框，是整款扩展里最有「场景感」的一页，但入口是弹窗里的一行「打开主题页」。
- 用户习惯是：新标签 = 新标签页 / 首页，选项 = 设置。不会想到「去设置页找氛围」。
- **结论**：最好的体验没有和**高频动作（开新标签）**绑定，存在感弱。

### 4. 心智模型模糊：「我什么时候该用？」

- 没有场景提示：是工作阅读用？摸鱼氛围用？做梗图用？用户要自己脑补。
- 弹窗只传达「开/关」，没有传达「适合在什么情境用」「能多快看到效果」。
- **结论**：**使用场景不清晰**，导致「有用」感不足。

### 5. 和「日常」没有绑定

- 除了「我主动去某个网页再开开关」之外，没有别的触点。没有新标签页、没有每日一句、没有「每次打开浏览器就自然看到 Y2K」的习惯锚点。
- **结论**：**缺少一个每天都会碰到的入口**，自然难留。

---

## 二、「好用」的目标可以怎么定义

不追求「功能多」，而追求这几条：

| 维度 | 目标 |
|------|------|
| **10 秒内懂** | 安装/首次打开时，立刻看到「网页变复古」的效果或演示，不用猜。 |
| **有一个可带走的成果** | 用户能「做出一件东西」：一张 Y2K 风格图、一个可分享链接/卡片，而不只是「看」。 |
| **有一个每天会碰到的入口** | 至少一个高频场景（例如新标签页）和 Y2K 强绑定，形成习惯。 |
| **场景说人话** | 文案/引导里明确说：适合「摸鱼氛围」「做梗图」「怀旧阅读」等，让用户对号入座。 |

## 三、改进方向（按优先级）

### 方向 A：让「价值」在 10 秒内可见（优先）

**要解决的问题**：装完不知道有啥用、不知道效果长什么样。

**可做**：

1. **首次安装 / 首次打开弹窗**  
   - 自动打开一个**演示页**（extension 自带的一个 HTML 页）：左边「正常」、右边「Y2K 后」对比，或直接整页就是 Y2K 风格 + 一句「你打开的任意网页都能变成这样」。  
   - 或：首次打开弹窗时，弹窗内嵌一个**小预览区**（例如用 iframe 打开 chrome-extension 里的 demo 页），让用户不离开弹窗就看到效果。

2. **弹窗文案升级**  
   - 标题/副标题不说「复古模式」，而说结果：「把当前网页变成 90s/Y2K 风格」；下面再是开关。  
   - 可选：加一行「点击这里看效果示例」→ 打开上述演示页。

**验收**：新用户装完，不读文档也能在 10 秒内说出「这东西是干嘛的」。

---

### 方向 B：新标签页 = Y2K 首页（优先）

**要解决的问题**：最有氛围的 XP+搜索 藏在选项里，且没有每日触点。

**可做**：

1. **用 Chrome 的 `chrome_url_overrides.newtab`**  
   - 把现在的「选项页」（XP 壁纸 + 搜索）改成**新标签页**；或新建一个「新标签页」入口，内容和现有选项页一致/增强。

2. **新标签页适度增强**  
   - 保留：XP 壁纸 + 搜索（已有）。  
   - 可加（不一次做完）：  
     - 日期 + 一句 Y2K 风格文案（「Welcome to the Web. Today is …」）；  
     - 可选：一个「随机打开一个 Y2K 风格示例站点」的按钮（你挑几个安全、有代表性的站点），让「开新标签」偶尔变成小彩蛋。  

这样「开新标签」= 每天多次看到 Y2K，习惯和存在感都会上来。

**验收**：用户打开新标签就会看到 Y2K 氛围，且能直接搜索，不用去选项。

---

### 方向 C：有一个「可带走的成果」（中优先）

**要解决的问题**：用完了什么都没有，没有分享欲和归属感。

**可做**：

1. **一键生成「Y2K 风格截图」**  
   - 在弹窗或内容脚本里加一个入口：「把当前页截成 Y2K 风格图」。  
   - 流程：用现有注入逻辑渲染当前页 → 用 `chrome.tabs.captureVisibleTab` 或页面内 canvas 截取可见区域（可加简单边框/水印/日期）→ 下载或「复制到剪贴板」。  
   - 用户得到一张图，可发推/发朋友圈，形成「这是我用 Y2K 做的」。

2. **后续可扩展**  
   - 「Y2K 风格链接卡片」：输入 URL，生成一张可分享的复古风格卡片图（带标题、缩略图、Y2K 边框）。  
   - 先不做也行，但「当前页截图」是性价比最高的一步。

**验收**：用户能在一分钟内做出一张「Y2K 风格」的图并保存/分享。

---

### 方向 D：场景化文案与轻引导（中优先）

**要解决的问题**：不知道「什么时候用」「适合谁」。

**可做**：

1. **商店描述 / 选项页 / 弹窗**里加一句场景化描述，例如：  
   - 「适合：摸鱼时给网页加点复古味、做梗图、怀旧阅读。」  

2. **弹窗**  
   - 在开关下面加一行小字：「在任意网页打开时自动生效」，减少「我开了怎么没反应」的困惑。  

3. **可选**：在首次打开弹窗时，用 1 个 tooltip/高亮指向「复古模式」开关，并写「打开后，当前页会变成 90s 风格」。  

**验收**：用户能对号入座「我就是要摸鱼/做图」，并且知道开了开关会怎样。

---

### 方向 E：主题/皮肤（可后置）

**要解决的问题**：只有一套复古风，玩一次就腻。

**可做**：  
- 在选项/新标签页里提供 2～3 套风格（例如：经典灰蓝 / 霓虹紫粉 / 故障 Glitch），存到 `storage`，background 按选择注入对应 CSS。  
- 实现可以后面再做，思路先留：让「换皮肤」成为一个小目标，增加回访。

---

## 四、建议的落地顺序

1. **先做 A + B**  
   - A：首次见到的「效果可见」+ 弹窗文案；  
   - B：新标签页 override，把 XP+搜索 推到新标签。  
   → 解决「不知道有啥用」和「没有每日触点」，成本相对低。

2. **再做 C 的「当前页 Y2K 截图」**  
   - 给用户一个明确产出，方便分享和回忆。

3. **然后 D（场景文案 + 轻引导）**  
   - 配合 A/B/C 一起，让「好用」被说清楚。

4. **E 主题**  
   - 在留存和反馈稳定后再加，作为「玩得更久」的增强。

---

## 五、一句话小结

**「还不够好用」** 主要是因为：  
价值出现太晚、没有可带走的成果、最好的页面没和高频动作绑定、使用场景没说清、没有每日触点。

**更好用的路线**：  
先让「装完 10 秒内看到效果」+「新标签页 = Y2K 首页」，再补「一键生成 Y2K 图」和场景化文案，这样既有「懂」、又有「用」、还有「习惯」，留存和口碑会更容易上去。
