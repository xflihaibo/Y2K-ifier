# 归航时刻 · 完整动画效果说明

**总时长**：4 秒（4000ms）  
**悬浮框出现**：4s 时插入 DOM，再播 0.85s 入场动画。

---

## 一、层级结构（从底到上）

| 顺序 | 图层 ID | 作用 |
|------|---------|------|
| 1 | y2k-ritual-effect-yellow | 发黄：傍晚暖色罩住整页 |
| 2 | y2k-ritual-effect-scanlines | 扫描线：CRT 横向线纹理 |
| 3 | y2k-ritual-effect-breathe | 呼吸：轻微明暗起伏 |
| 4 | y2k-ritual-effect-dim | 变暗：径向从中心向四角变黑 |
| 5 | y2k-ritual-effect-flash | 磷光闪：关机前一次暖黄闪（约 2.96s 处） |
| 6 | y2k-ritual-effect-line | **中心线**：中间亮、两边淡，**仅占屏幕宽 60%、居中** |
| 7 | y2k-ritual-effect-flash-white | **三次亮白闪**：细线阶段的 3 次白闪 |
| 8 | y2k-ritual-effect-grain | 噪点：胶片感纹理 |

整块由 **#y2k-ritual-effect-overlay** 包住，对 overlay 做 **scaleY** 收束；所有子层一起被压成一条线。

---

## 二、主时间轴（4s）

| 时间 | 进度 | 主视觉 |
|------|------|--------|
| 0s | 0% | 开始 |
| 0～2.2s | 0%～55% | 发黄、扫描线、呼吸、变暗、噪点陆续出现并稳定 |
| ≈2.96s | 74% | 满屏保持，磷光闪（暖黄）约在 75% 前后出现一次 |
| 3.12s | 78% | **收束开始**：scaleY 1 → **0.4**（先收到 40% 高） |
| 3.2s | 80% | scaleY 0.2 |
| 3.32s | 83% | scaleY 0.1 |
| 3.44s | 86% | scaleY 0.08 |
| 3.52s | 88% | scaleY 0.04，**中心线层**在 78%～88% 淡入（0→0.4→1） |
| 3.6s | 90% | scaleY **0.002**（约 1 像素高），**60% 宽、居中的亮线**稳定 |
| 3.64s | 91% | **第 1 次亮白闪**（flash-white 0.92） |
| 3.67s | 91.8% | **第 2 次亮白闪**（0.88） |
| 3.7s | 92.6% | **第 3 次亮白闪**（0.82） |
| 3.72s | 93% | 闪结束，overlay 保持细线、opacity 1 |
| 3.84s | 96% | overlay opacity → 0.08 |
| 4s | 100% | overlay opacity → 0，特效层移除，**右下角悬浮框出现** |
| 4～4.85s | — | 悬浮框 0.85s 入场：上浮 + 淡入 + 轻微 overshoot + 光晕 |

---

## 三、各层动画参数

### 1. 发黄（yellow）
- **时长**：2.2s，无 delay  
- **缓动**：cubic-bezier(0.22, 0.61, 0.36, 1)  
- **关键帧**：opacity 0 → 0.35(25%) → 0.72(55%) → 0.95(82%) → 1(100%)  
- **背景**：上下渐变 rgba(255,250,235～255,238,195)

### 2. 扫描线（scanlines）
- **时长**：1.8s，**delay 0.6s**  
- **关键帧**：opacity 0 → 0.22(20%) → 0.55(45%) → 0.78(70%) → 0.9(88%) → 0.92(100%)  
- **样式**：repeating-linear-gradient 横向细线，2px 透明 + 1px 深色

### 3. 呼吸（breathe）
- **时长**：2.8s，**delay 0.4s**  
- **关键帧**：opacity 0 → 0.18 → 0.38 → 0.22 → 0.45 → 0.28 → 0.35 → 0.3  
- **作用**：轻微明暗起伏，像老显示器还在“哼”

### 4. 变暗（dim）
- **时长**：1.7s，**delay 1s**  
- **关键帧**：opacity 0 → 0.18(22%) → 0.42(45%) → 0.68(68%) → 0.88(85%) → 1(100%)  
- **背景**：径向椭圆，中心稍亮、四角更黑

### 5. 磷光闪（flash，暖黄）
- **时长**：4s  
- **关键帧**：74% 前 0；75.5% 0.95；76.5% 0.5；77.5% 0.18；78.5% 0.06；79.5% 0.02；81%～100% 0  
- **作用**：关机前一次暖黄闪 + 余晖

### 6. 中心线（line）— 60% 宽、居中
- **布局**：`left: 20%; width: 60%; top: 0; bottom: 0`（水平居中 60% 宽）  
- **时长**：4s  
- **关键帧**：0%～78% opacity 0；82% 0.4；88%～100% 1  
- **背景**：横向渐变，中间 rgba(255,252,248,0.98)，两侧 rgba(255,248,220,0.45)，再向两边透明 → **中间亮、两边淡**

### 7. 三次亮白闪（flash-white）
- **时长**：4s  
- **背景**：rgba(255,255,255,0.95)  
- **关键帧**：  
  - 0%～90.5%：0  
  - **91%**：0.92 → **91.35%**：0  
  - **91.8%**：0.88 → **92.15%**：0  
  - **92.6%**：0.82 → **92.95%**：0  
  - 93%～100%：0  

### 8. 噪点（grain）
- **时长**：2s，**delay 0.8s**  
- **关键帧**：opacity 0 → 0.04(40%) → 0.07(100%)  
- **样式**：SVG feTurbulence 噪点，mix-blend-mode: overlay

### 9. 整体收束（collapse，作用在 overlay）
- **时长**：4s  
- **缓动**：cubic-bezier(0.22, 0.61, 0.36, 1)  
- **scaleY**：  
  - 0%～74%：1（满屏）  
  - 78%：**0.4**  
  - 80%：0.2  
  - 83%：0.1  
  - 86%：0.08  
  - 88%：0.04  
  - 90%～100%：**0.002**（约 1 像素高）  
- **opacity**：0%～93% 为 1；96% 为 0.08；100% 为 0（整块淡出）

### 10. 悬浮框（float）
- **插入时机**：4s（RITUAL_FLOAT_DELAY_MS = 4000）  
- **入场动画**：0.85s，cubic-bezier(0.34, 1.12, 0.64, 1)  
- **关键帧**：opacity 0→1；translateY 20px→-3px→0；scale 0.97→1.01→1；drop-shadow 无→强→略弱  

---

## 四、一句话流程

**发黄与扫描线、呼吸、变暗、噪点、磷光闪** → **画面按 scaleY 多段收窄（1→0.4→0.2→0.1→0.08→0.04→0.002）** → **60% 宽、中间亮两边淡的线在收束中淡入** → **细线稳定后 3 次亮白闪** → **整块淡出** → **4s 时移除特效并出现右下角归航悬浮框，带 0.85s 入场动画**。
