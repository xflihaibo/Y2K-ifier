# Y2K-ifier 业务逻辑与目前开发任务

> 用于梳理产品逻辑与当前/后续开发任务，便于迭代与交接。

---

## 一、业务逻辑梳理

### 1.1 产品定位与核心价值

| 维度 | 说明 |
|------|------|
| **产品名** | Y2K-ifier: 网页复古重塑计划（90s Retro Filter & Web Nostalgia） |
| **类型** | Chrome 扩展，Manifest V3，**单一用途**：网页视觉复古 |
| **核心价值** | 通过「手术级」CSS 注入，把现代网页的**装饰性元素**变成 2000 年代初的复古美学，不改变布局与功能 |
| **合规** | 不收集数据、不请求无关权限；书签仅用于怀旧助手随机推荐，足迹数据仅存本地 |

**一句话**：装扩展 → 开/关复古 → 任意网页变成 Y2K 风格；再通过主题页、归航时刻、今日足迹等粘性功能增强留存。

---

### 1.2 核心功能与用户流程

#### A. 视觉重塑（核心）

- **复古模式**：注入 `retro.css`，实现 3D 按钮、衬线字体、直角、像素化图片、复古滚动条/光标等。
- **CRT 模式**：在复古基础上增加扫描线、跑马灯、「正在建设中」挂件等。
- **流程**：用户打开 Popup → 切换「复古」「CRT」→ 状态写入 `chrome.storage.local` → Background 监听 storage + `tabs.onUpdated`，对当前/新加载的普通网页执行 `chrome.scripting.insertCSS` / 移除。
- **排除**：`chrome://`、`edge://`、`about:`、扩展商店等不注入。

#### B. 主题页（Newtab 页 / 选项页）

- **入口**：Popup「打开主题页」、快捷键 **Alt+Shift+Y**（Mac：Option+Shift+Y）、扩展选项页（与主题页共用同一页面）。
- **内容**：XP 壁纸（`public/images/xp.jpeg`）、搜索栏（谷歌/必应/百度，持久化 `optionsSearchEngine`）、右下角**怀旧助手**（NostalgicAgent）。
- **怀旧助手**：50 条预设话术（中英）、「再说一句」随机换句、「随机推荐一个书签」（`chrome.bookmarks.getTree`，无 LLM）。
- **设计**：**不覆盖**浏览器默认新标签页（无 `chrome_url_overrides.newtab`），用户需主动打开主题页或设快捷键。

#### C. 粘性功能（留存）

| 功能 | 逻辑概要 | 存储键 |
|------|----------|--------|
| **陪伴天数 + 里程碑** | 每次打开 Popup 或主题页记为「活跃日」，弹窗展示累计天数与徽章（拨号新手→网虫→冲浪达人→老网民→骨灰级→一年之约） | `y2kActiveDays`（日期字符串数组，最多 365） |
| **晨间问候** | 每天首次打开 Popup 显示一条 Y2K 风格问候，可关闭，当日不再显示 | `y2kGreetingClosedDate` |
| **每日归航时刻** | 用户设置提醒时间（如 18:00）；到点后 alarm 触发：当前普通网页上出现**归航动画**（变色/三闪/收线）→ 热敏纸小票滑出 → 右下角悬浮「归航」头像；点击头像打开今日信息卡片（冲浪日志、时间轴、统计）。可选同时打开带 `?ritual=1` 的主题页 | `y2kRitualEnabled`、`y2kRitualTime`、`y2kRitualDates`（归航触发日期，用于「本月归航 X 次」「连续 X 天」） |
| **今日足迹** | Background 在切 tab 时维护当前页记录；Content Script 统计点击、滚动、输入字数、可见停留时长，定期上报；Pop up 展示今日列表（标题/域名、时长、点击数），点击可新标签打开 | `y2kBrowsingData`（今日访问列表，含 url/title/icon/visitTime/activeDuration/clicks/scrollDistance/charsTyped） |

归航动画与卡片逻辑在 **Content Script**（`src/content.ts`）中：接收 `RITUAL_SHOW` 消息后插入 overlay 动画、小票、悬浮头像与信息卡片；文案与统计来自 Background 汇总的今日数据。

### 1.3 数据流与存储键汇总

| 存储键 | 含义 |
|--------|------|
| `isEnabled` | 复古模式开/关 |
| `crtEnabled` | CRT 扫描线/跑马灯开/关 |
| `optionsSearchEngine` | 主题页搜索引擎（如 google/bing/baidu） |
| `locale` | 语言（中/英） |
| `y2kActiveDays` | 活跃日日期数组（最多 365） |
| `y2kGreetingClosedDate` | 晨间问候关闭日期（当日不再显示） |
| `y2kRitualEnabled` / `y2kRitualTime` | 归航提醒开关与时间 |
| `y2kRitualDates` | 归航触发日期列表（本月/连续统计） |
| `y2kBrowsingData` | 当日浏览记录（含停留、点击、滚动、输入） |

**消息流**：

- Popup/Newtab ↔ Background：`chrome.runtime.sendMessage` / `chrome.storage.local`。
- Background → Content：`chrome.tabs.sendMessage`（注入/移除 CSS、归航 `RITUAL_SHOW`、请求今日统计等）。
- Content → Background：`chrome.runtime.sendMessage`（上报点击/滚动/输入/停留）。

---

### 1.4 技术架构要点

- **构建**：Vite 5 + Vue 3 + TypeScript，`@samrum/vite-plugin-web-extension`，产物 `dist/`。
- **Background**：Service Worker（`src/background/background.ts`），负责注入、alarms、storage 监听、书签/今日数据汇总。
- **Content**：`src/content.ts`，单文件内：页面内统计、归航动画与卡片、与 Background 通信。
- **多语言**：vue-i18n（runtime），`src/locales/en.ts`、`zh-CN.ts`，locale 存 storage。
- **样式**：`public/styles/retro.css` 高优先级 + `all: initial` 等隔离手段，尽量只改装饰不改布局。

### 2.2 建议优先做（体验/稳定性）

来自 `docs/optimization-checklist.md`：

| 序号 | 任务 | 说明 |
|------|------|------|
| 1 | 主题页打开失败提示 | `chrome.tabs.create` 失败时无反馈，可在 Popup 的 `openThemePage()` 里 `.catch` 并 toast「打开失败，请重试」 |
| 2 | 壁纸缺失说明 | 未放置 `xp.jpeg` 时背景为纯色，可在 newtab 页脚或 `public/images/README.md` 注明「未检测到壁纸时使用默认背景」 |

### 2.4 留存与「好用」方向（产品级）

来自 `docs/retention-and-ux-thinking.md`，可作为后续迭代方向，非当前必做：

- **10 秒内懂**：首次安装/首次打开弹窗时，自动打开演示页或弹窗内小预览，让用户立刻看到「网页变复古」效果。
- **可带走的成果**：提供「做出一件东西」的产出（如 Y2K 风格截图、分享卡片），而不只是「看」。
- **每日入口**：新标签页与 Y2K 强绑定（当前为不覆盖新标签 + 快捷键，是否改为覆盖可再评估）。
- **场景说人话**：文案中明确「摸鱼氛围」「做梗图」「怀旧阅读」等使用场景。

## 三、一句话总结

**业务**：Y2K-ifier 用「手术级」CSS 把网页变成 2000 年代复古风格，配合主题页、陪伴天数、晨间问候、归航时刻、今日足迹做留存；数据全部本地，单一用途合规。

**开发**：基础功能与粘性功能已实现；当前任务以**体验与稳定性**为主（主题页打开失败提示、壁纸说明、书签权限引导），再按需做代码/体积优化与 RAG/多主题等后续迭代。
