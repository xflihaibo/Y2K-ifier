# 需求文档 - Y2K-ifier (2000年代复古化插件)

## 概述
**Y2K-ifier** 是一款谷歌浏览器扩展插件，旨在通过“手术级”的视觉重塑，将现代网页的风格转化为 2000 年代的复古审美。其核心目标是在不破坏原始网站可用性或布局的前提下，为用户提供纯粹的怀旧体验。

## 用户故事
| ID | 用户故事 | 验收标准 |
|----|------------|---------------------|
| US.1 | **切换复古风格** | 用户必须能够通过插件弹出界面（Popup）开启或关闭复古转换。 |
| US.2 | **手术级视觉重塑** | 现代 UI 元素（按钮、标题、文本、图片）应看起来像来自 2000 年。 |
| US.3 | **布局保护** | 转换过程中不得改变页面上任何元素的大小、位置或原始布局。 |
| US.4 | **状态持久化** | 开启/关闭状态必须在不同标签页和浏览器重启后保持。 |
| US.5 | **跨站兼容性** | 插件应能在各种现代网页结构上稳定运行。 |

## 功能需求
- **FR.1: CSS 注入**：插件必须将特定的“复古样式表”注入到当前活动标签页中。
- **FR.2: 手术级目标定位**：
    - **按钮 (Buttons)**：应用 3D 凸起边框和灰色背景 (`#c0c0c0`)。
    - **排版 (Typography)**：标题强制使用衬线字体 (Times New Roman)，正文使用无衬线字体 (Arial/MS Sans Serif)。强制链接显示蓝色及下划线。
    - **图片 (Images)**：应用低保真滤镜（像素化渲染、轻微的褐色/对比度调节）。
    - **滚动条 (Scrollbars)**：重塑滚动条外观，使其匹配经典的 Windows 2000 风格。
- **FR.3: 开关逻辑**：使用 `chrome.storage.local` 管理持久化的开关状态。
- **FR.4: 用户界面**：提供一个带有开关按钮的简洁弹出界面。

## 非功能需求
- **NFR.1: 性能**：CSS 注入应接近即时，且不引起明显的布局偏移（Layout Shift）。
- **NFR.2: 隐私**：纯前端开发，不收集任何数据，不调用外部 API。
- **NFR.3: 可靠性**：注入的 CSS 必须谨慎使用 `!important`，以有效但克制地覆盖现代网站样式。

## EARS 标准合规性
- **事件驱动 (Event-driven)**：*当* 用户切换开关时，*系统应* 应用或移除复古 CSS。
- **普遍存在 (Ubiquitous)**：*在* 插件激活的情况下，*系统应* 为所有按钮添加 3D 凸起边框。
- **异常行为 (Unwanted Behavior)**：*如果* 网站使用了复杂的图标字体，*系统应* 尝试排除这些元素的字体族覆盖，以保持图标的可用性。
